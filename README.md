# Live Chat - Projeto de Chat ao Vivo com IA

Este projeto é um aplicativo de chat ao vivo multiusuário com integração de inteligência artificial, que permite comunicação em tempo real entre usuários, além de respostas automáticas via IA.

---

## Sobre o projeto

Este projeto foi inspirado em um desafio proposto pelo canal **CodeCon**, que incentiva programadores a criarem soluções práticas e eficientes utilizando tecnologias modernas.

---

## Funcionalidades

- Chat multiusuário em tempo real  
- Integração com IA para respostas automáticas  
- Interface intuitiva e responsiva  

> **Obs:** O banco de dados ainda não foi integrado nesta versão. A inclusão do PostgreSQL será o primeiro update da próxima versão.

---

## Tecnologias utilizadas

- React + TypeScript (frontend)  
- Node.js + Express (backend)  
- OpenAI API (ou outra IA integrada)  
- Git para controle de versão  

---

## Como executar o projeto

- cd backend && npm install
- cd ../frontend && npm install
- npm run start:server
- npm run start:client

- Criação arquivo .env configuração OPENAI_API_KEY="sua-chave-aqui" PORT=4000

### Pré-requisitos

- Node.js instalado  
- Conta e chave de API para o serviço de IA (ex: OpenAI)
